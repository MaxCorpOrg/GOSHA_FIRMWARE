# Проверка маршрута команды до вызовов PWM

Из корня репозитория:

```bash
python3 firmware/scripts/run_right_arm_pwm_route_host_test.py
```

Нужны Python 3.10+ и g++. По умолчанию включены ASan/UBSan; ошибка сборки
или теста завершает проверку с ненулевым кодом. `--no-sanitize` явно
отключает эти инструменты и не является проверкой с ними. Исполняемый файл
создаётся в отдельной временной папке и удаляется после завершения.

Тест компилирует настоящие `MotionLiveCore`, `Otto` и `Oscillator`, а системные
функции ESP-IDF/FreeRTOS заменяет минимальными заглушками. LEDC-регистратор
запоминает настройку каналов, set/update duty и остановку. Callback привязки
каналов задаёт тест по контракту `OttoController`; сетевой адаптер и сам
контроллер не входят в сборку. Это не полная сборка прошивки и не измерение
сигнала на реальном выводе. Регистратор не моделирует электрическую схему,
внутреннее устройство LEDC, нагрузку, механику или энергосбережение платы.

Проверяются раздельное включение четырёх ног/ступней и правой руки, разные
каналы, шаг 135° → 130° при 1°/с, пара set/update для правого GPIO12,
неизменная нейтраль ног, отсутствие левой руки и отсутствие дополнительных
PWM-вызовов от STOP/watchdog. Ключевые ожидаемые duty заданы константами
614/819/796, независимо от формулы в реализации.

Заглушки используются только этим runner и не подключаются к ESP-IDF.
Проверка не открывает сеть или serial и не посылает команд роботу.
