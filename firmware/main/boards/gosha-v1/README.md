# gosha-v1

Профиль `gosha-v1` — первая собственная точка прошивки `Гоша`, созданная как безопасная копия профиля `otto-robot`.

## Назначение

- сохранить исходный `otto-robot` как эталон сравнения;
- вынести собственные аппаратные и продуктовые правки в отдельный профиль;
- подготовить первую самостоятельную сборку `Гоша` без вмешательства в исходный профиль.

## Текущее состояние

- Профиль уже содержит собственные продуктовые параметры `Гоша`, экранный профиль, локальный управляющий контур и подтверждённый объединённый образ.
- На новом устройстве `2026-08-23` подтверждены `ESP32-S3` ревизии `v0.2`, вариант `non-camera`, `16 MB` flash-памяти и `8 MB PSRAM`.
- Полная установка потребовалась из-за несовместимой заводской таблицы разделов и выполнена только после полного резервного копирования flash-памяти.
- Программный канал левой руки на `GPIO8` подтверждён перекрёстным тестом.
  Неисправный физический сервопривод левой руки отключён от платы и должен
  оставаться отключённым. Остальные аппаратные проверки разрешены по
  `docs/HARDWARE_DEVELOPMENT_POLICY_RU.md`.
- Полная аппаратная проверка опирается на документы верхнего уровня:
  - `../../../../docs/HARDWARE_MANIFEST_RU.md`
  - `../../../../docs/PIN_MAP_RU.md`

## Ближайшие шаги

- сохранить Draft/Open состояние PR `#24`, а новые устанавливаемые кандидаты
  готовить в отдельной ветке с rollback и hardware evidence;
- подобрать совместимую замену левой сервы, сначала проверить её без качалки и нагрузки, выполнить `Home` и только затем установить механику;
- после замены провести малый тест руки штатным управляющим путём;
- продолжить подтверждение остальных строк аппаратного манифеста и карты выводов;
- для последующих выпусков использовать каноническую сборку `GOSHA_OTA_URL='<owner-only endpoint>' python3 scripts/release.py gosha-v1 --name gosha-v1`; скрипт не печатает значение endpoint и не хранит его в Git.
