# gosha-otto-v1

Профиль `gosha-otto-v1` — первая собственная точка прошивки `Гоша`, созданная как безопасная копия профиля `otto-robot`.

## Назначение

- сохранить исходный `otto-robot` как эталон сравнения;
- вынести собственные аппаратные и продуктовые правки в отдельный профиль;
- подготовить первую самостоятельную сборку `Гоша` без вмешательства в исходный профиль.

## Текущее состояние

- Этот профиль пока совпадает с `otto-robot` по аппаратной базе и логике.
- Первая целевая ревизия считается вариантом `non-camera`, пока не подтверждено обратное на реальном устройстве.
- Полная аппаратная проверка опирается на документы верхнего уровня:
  - `../../../../docs/HARDWARE_MANIFEST_RU.md`
  - `../../../../docs/PIN_MAP_RU.md`

## Ближайшие шаги

- подтвердить аппаратный манифест и карту выводов;
- проверить сборку профиля через `scripts/release.py gosha-otto-v1`;
- затем переводить внешнее имя платы и другие продуктовые тексты на бренд `Гоша`;
- после первой успешной сборки переходить к реальной прошивке тестового устройства.
