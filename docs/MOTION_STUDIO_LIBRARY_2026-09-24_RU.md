# Motion Studio: сохранная библиотека пакетов

24 сентября 2026. Ветка `codex/motion-studio-library-20260924` начата от
`codex/restore-robot-route-20260923` (`21e35d2`), то есть от исходников
последнего принятого app `bb2aece0…a7c4e9`. Установленный робот и сервер
этой задачей не менялись.

## Что реализовано

- До трёх пользовательских пакетов видны одновременно; четвёртый физический
  слот используется для проверенной записи обновления. При попытке добавить
  четвёртый пакет возвращается `store_full`, прежние записи не удаляются.
- Обновление выполняется по постоянному `package_id`: новая запись сначала
  пишется в свободный слот и перечитывается, затем одним ключом каталога
  переключается видимая версия. При ошибке записи или проверки старая версия
  остаётся доступной. Выбор и удаление используют тот же каталог.
- Первые два пакета старого формата читаются без переписывания. Перед первой
  миграцией сохраняется маркер со снимком старого каталога; при отключении
  питания до записи нового каталога робот видит старые пакеты и может
  повторить операцию. При отсутствии нового каталога без маркера данные
  закрываются с ошибкой `store_catalog_missing`, а не выдаются за старые.
- Возможность объявлена как `package_features.store_slots: 3`.
  Названия, данные пакетов, аппаратный ноль 135° и 27 встроенных движений
  не менялись. Размер раздела NVS не расширялся.

Код хранит только одну актуальную версию каждого ID. Для восстановления
предыдущего авторского варианта Studio хранит локальный снимок движения;
перед аппаратной установкой нужен полный снимок NVS с двумя исходными
пакетами. При откате на старую прошивку после новых записей требуется вернуть
этот снимок NVS: старая прошивка не понимает новый каталог.

## Проверки и выпуск

Host-тесты `motion_package_store`, `motion_package_manager` и
`motion_package_protocol` прошли. Они проверяют заполнение, обновление,
сбой записи и коммита, прерванную первую миграцию, старые A/B, выбор и
удаление. Отдельно выполнена сборка ESP-IDF 5.5.2 с закрытым профилем Live
и точным `sdkconfig` принятой прошивки; все `CONFIG_GOSHA_*` совпадают.

Кандидат app-only: `AI_ROBOTS/local_only/motion-studio-candidate-20260924/gosha.bin`,
3 719 840 байт, SHA-256
`8bcb0c3a762c270d4f84ae4665c8df83257410e1ee7ea5a944efc1f70737a0b8`.
Это подготовленный образ, не установленная прошивка. Исходный принятый app
остаётся на роботе. Для установки требуются аппаратное окно и проверки из
`docs/HARDWARE_DEVELOPMENT_POLICY_RU.md`, включая подтверждение состояния
левой руки, устойчивой опоры, резервный снимок app и NVS, отдельную сверку
записи и путь отката. Движение требует отдельного допуска владельца.

Свободное место NVS на устройстве ещё не измерено. Исходные пакеты имеют
payload 1300 и 2305 байт по последнему чтению 23 сентября; запись малого
третьего пакета должна быть подтверждена на устройстве. Ошибка нехватки
памяти отклонит запись без вытеснения старых данных.
