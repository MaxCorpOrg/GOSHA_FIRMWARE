# Контрольная точка одноразового импорта прошивки

## Источник импорта

- Канонический источник первого импорта:
  - `/home/max/MAX_CORP_CORE/AI_ROBOT/xiaozhi-esp32`
- Зафиксированная версия исходной базы:
  - `PROJECT_VER "2.2.2"`

## Что импортировать

- дерево исходников прошивки;
- board-профиль `otto-robot` как отправную точку;
- связанные конфигурационные файлы сборки;
- только отслеживаемые исходники и документы, без build-артефактов.

## Что не импортировать

- живое состояние `AI_ROBOT`;
- build-каталоги;
- временные двоичные файлы;
- локальные `sdkconfig`;
- любые результаты старых сборок, кроме отдельного эталона сравнения и отката.

## Эталон сравнения

- Для сравнения и отката использовать:
  - `/home/max/MAX_CORP_CORE/AI_ROBOT/new/v2.0.5_otto-robot/merged-binary.bin`

## Правила первого этапа после импорта

- Не смешивать импортированное дерево с `GOSHA_PLATFORM`.
- Сначала создать новый профиль `gosha-otto-v1` как копию `otto-robot`.
- Сначала подтвердить аппаратный манифест и pin map, потом править аппаратные выводы и поведение платы.
- Сначала собрать один базовый `merged-binary.bin`, потом уже делать последующие аппаратные и продуктовые изменения.
