# AGENT CHECKPOINT

## Что это за проект

`GOSHA_FIRMWARE` — отдельный репозиторий собственной прошивки `Гоша`, который должен привести к независимому устройству с собственной платформой и собственным профилем платы.

## Как писать новые записи

- Все новые планы, отчёты, объяснения и контрольные точки оформляй русским техническим языком по правилам из `../AGENTS.md`.
- Не используй необъяснённый английский жаргон в обычном тексте.
- Английский оставляй только для команд, путей, имён файлов, веток, коммитов и кода.

- Канонический исходный профиль первой версии:
  - `otto-robot`
- Новый целевой профиль:
  - `gosha-otto-v1`
- Зафиксированы предварительные аппаратные документы:

## Главные ограничения

- Не превращать `AI_ROBOT` в живую зависимость нового репозитория.
- Не хранить build-артефакты и локальные `sdkconfig` в git.
- Не делать рискованные аппаратные изменения до подтверждения манифеста и pin map.
- Не смешивать этот репозиторий с `GOSHA_PLATFORM`.
