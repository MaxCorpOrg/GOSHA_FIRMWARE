## Что это за проект

`GOSHA_FIRMWARE` — отдельный репозиторий собственной прошивки `Гоша`, который должен привести к независимому устройству с собственной платформой и собственным профилем платы.

- Все новые планы, отчёты, объяснения и контрольные точки оформляй русским техническим языком по правилам из `../AGENTS.md`.
- Не используй необъяснённый английский жаргон в обычном тексте.
- Английский оставляй только для команд, путей, имён файлов, веток, коммитов и кода.
