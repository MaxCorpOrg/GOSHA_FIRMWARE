# GOSHA_FIRMWARE

`GOSHA_FIRMWARE` — отдельный репозиторий собственной прошивки проекта `Гоша`.

## Назначение

- вынести прошивку в отдельный независимый контур;
- убрать прямую продуктовую зависимость от чужой платформы;
- подготовить собственный профиль платы `gosha-v1`;
- направить робот на собственную платформу `GOSHA_PLATFORM`;
- сохранить совместимые технические маршруты только как временный слой совместимости там, где это реально нужно.

## Основная идея первой версии

- Базовый аппаратный профиль берём из `otto-robot`.
- Новый целевой профиль называем `gosha-v1`.
- Первая версия прошивки должна работать как часть масштабируемого проекта `Гоша`:
  - один робот может переключаться между разными ИИ-агентами через платформу без перепрошивки;
  - выбор поставщика ИИ должен происходить на стороне `GOSHA_PLATFORM`, а не быть жёстко вшитым в устройство.
- Имя точки доступа строим так:
  - семейство `GOSHA-A`
  - уникальность берём из хвоста `MAC`-адреса
  - итоговый вид: `GOSHA-A-XXXX`
  Это лучше, чем фиксированное `1AA1`, потому что устройство остаётся уникальным без центральной регистрации.

## С чего начинать следующий этап

1. Открыть `START_HERE_FOR_NEW_CHAT.md`.
2. Прочитать `/home/max/GOSHA_PLATFORM/docs/GOSHA_PROJECT_MAP_RU.md`.
3. Прочитать `docs/FIRMWARE_IMPORT_CHECKPOINT_RU.md`.
4. Подтвердить аппаратный манифест и pin map.
5. Проверить аппаратный манифест и pin map.
6. Проверить видимость `gosha-v1` в сборочных инструментах.
7. Подтвердить на тестовом устройстве русский экран, русские голосовые подсказки и новое имя точки доступа.
8. Прошить одно тестовое устройство и пройти аппаратную проверку.
